Vendor bills from scans, filled by AiParsy

Ukrainian waybills, acts of work and supplier invoices become draft vendor bills with the vendor, number, date, lines and VAT

How it works

  1. Upload a scan or photo to a draft vendor bill and press Recognize with AiParsy — or send a batch of scans at once from Vendors → Send scans to AiParsy.
  2. AiParsy recognizes the document. The accountant checks it in AiParsy and approves it.
  3. AiParsy fills the same draft bill in Odoo: the vendor (found by ЄДРПОУ or created), the bill number and date, the lines with prices without VAT and the Odoo purchase tax of the right rate (20, 14, 7 or 0 %).

Each bill shows its AiParsy status: recognizing, recognized, approved, filled. A scheduled action refreshes the statuses every 10 minutes; the AiParsy button opens the document in AiParsy.

Setup in five minutes

  1. Create a free account at aiparsy.com.
  2. In AiParsy open API Keys and create a key.
  3. In Odoo: Accounting → Configuration → Settings → AiParsy — paste the key and press Check connection.
  4. In Odoo create an API key for the user AiParsy will work as (My Profile → Account Security → New API Key).
  5. In AiParsy open Accounting systems → Odoo and enter the Odoo address and database shown in the settings, the login and that API key.

Recognition uses the pages of your AiParsy plan. AiParsy needs to reach your Odoo over the internet to fill the bills (Odoo.sh or your own server with a public address). Step-by-step guide: aiparsy.com/blog/odoo.
